# Slik optimaliserer du gaming på hjemmekinoen

En hjemmekino er fantastisk for gaming – stor skjerm, surroundlyd og romfølelse. Men spill har andre krav enn film. Her optimaliserer vi systemet for begge deler.

## Hvem passer dette for?

Deg som gamer på PS5, Xbox Series X/S eller PC og vil ha best mulig opplevelse gjennom hjemmekinosystemet.

## Kortversjon

- Aktiver **spillmodus** på TV-en for lavest mulig input lag
- **HDMI 2.1** gir 4K/120Hz, VRR og ALLM
- Koble konsollen via **AVR** for surroundlyd – men sjekk at AVR-en støtter passthrough
- **VRR** (Variable Refresh Rate) eliminerer screen tearing
- Lydinnstillinger kan optimaliseres for gaming vs film

## Input lag – den viktigste gaming-metrikken

Input lag er forsinkelsen mellom du trykker en knapp og noe skjer på skjermen.

| Nivå | Input lag | Egnet for |
|------|-----------|-----------|
| Utmerket | Under 15 ms | Konkurransespill, FPS |
| Bra | 15–25 ms | De fleste spill |
| Akseptabelt | 25–40 ms | Singleplayer, eventyr |
| Problematisk | Over 40 ms | Merkbar forsinkelse |

### Slik reduserer du input lag

1. **Spillmodus**: Aktiver TV-ens spillmodus (reduserer bildebehandling, senker input lag dramatisk)
2. **ALLM** (Auto Low Latency Mode): TV-en bytter automatisk til spillmodus når konsollen sender signal
3. **Deaktiver bildebehandling**: Motion smoothing, støyreduksjon, upscaling – alt øker forsinkelsen

## HDMI 2.1 for gaming

### Viktige HDMI 2.1-funksjoner for gamere

| Funksjon | Hva det gjør |
|----------|-------------|
| **4K/120Hz** | Dobbel bildefrekvens for jevnere spill |
| **VRR** | Synkroniserer skjermens oppdateringsfrekvens med spillets framerate |
| **ALLM** | Automatisk spillmodus |
| **QFT** | Raskere bildebytte |

### Trenger du 4K/120Hz?

- **Ja, for**: Raske spill (FPS, racing), konkurransespill
- **Nei, for**: Rollespill, strategispill, eventyr med 30fps-mål
- Mange spill tilbyr valget mellom **ytelsesmodus** (120fps) og **kvalitetsmodus** (30/60fps med bedre grafikk)

## Kobling gjennom AVR

For surroundlyd i spill må konsollen kobles via AVR-en. Sjekk disse potensielle problemene:

### AVR-en støtter HDMI 2.1

Nyere AVR-er (fra ca. 2021+) støtter 4K/120Hz passthrough. Koble slik:

```
Konsoll → HDMI → AVR (HDMI 2.1-inngang) → HDMI → TV (HDMI 2.1-port)
```

### AVR-en støtter IKKE HDMI 2.1

Eldre AVR-er kan begrense signalet. Løsning:

```
Konsoll → HDMI → TV (HDMI 2.1-port)
TV → eARC → AVR
```

Konsollen sender bilde direkte til TV-en, og TV-en sender lyd tilbake via eARC.

**Ulempe**: Litt mer input lag, og noen lydformater kan begrenses.

## Lydinnstillinger for gaming

### Surroundlyd i spill

De fleste moderne spill støtter surroundlyd:

- **PS5**: Støtter Dolby Atmos (via oppdatering), 3D Audio med Tempest Engine
- **Xbox Series X/S**: Dolby Atmos (krever Dolby Access-app), DTS:X
- **PC**: Dolby Atmos, DTS:X, Windows Sonic (gratis)

### Tips for spillyd

- Bruk «upmixing» (Dolby Surround, DTS Neural:X) for spill uten native surround
- **Sett senterhøyttaleren litt høyere** – spilldialog er viktig
- Vurder en gaming-profil på AVR-en med justerte nivåer (mer dynamikk for spill)

## HDR i spill

- Bruk spillets HDR-kalibrering (finnes vanligvis i spillets innstillingsmeny)
- Sett TV-ens HDR-modus til spillmodus (kombinerer HDR med lav input lag)
- Noen spill har dårlig HDR-implementering – test manuelt

Les mer: [HDR-innstillinger guide](/guide/hdr-innstillinger-guide/)

## Spesifikke oppsett

### PS5

1. Innstillinger → Skjerm → 4K, 120Hz (aktiveres automatisk med riktig TV)
2. Innstillinger → Lyd → HDMI-enhet → Antall kanaler → 5.1 eller 7.1
3. Innstillinger → Lyd → Lydformat (prioritet) → Bitstream (Dolby)

### Xbox Series X

1. Innstillinger → Generelt → TV & visning → 4K, 120Hz, Dolby Vision for gaming
2. Innstillinger → Generelt → Volum og lyd → Bitstream, Dolby Atmos for hodetelefoner (krever app)
3. Aktiver VRR i skjerminnstillinger

## Sjekkliste

- [ ] TV-ens spillmodus aktivert
- [ ] ALLM konfigurert
- [ ] VRR aktivert på TV og konsoll
- [ ] HDMI 2.1-port brukt for konsollen
- [ ] Lydformat satt til surroundstøtte
- [ ] HDR kalibrert i spillet
- [ ] AVR-passthrough verifisert (4K/120Hz)

## Vanlige feil

- Glemmer å aktivere spillmodus (høy input lag)
- Kobler konsollen til feil HDMI-port (ikke alle støtter 2.1)
- Bruker «film»-modus under gaming (for mye bildebehandling)
- Har VRR deaktivert
- Forventer 4K/120Hz gjennom en eldre AVR
